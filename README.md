# Manhwa Arasseo!

[English](README.en.md)

Chrome 插件：截图识别韩漫对话框，把译文直接盖在韩文原文上。日漫请用 [MangaWakatta!](https://github.com/wren-11/manga-wakatta)。

支持**韩文漫画**，可以翻译成简体中文或英文。名字是韩语「만화 알았어」，意思是“漫画，知道啦～”。

适用于在线韩漫网站，比如 Lezhin、Bomtoon、Ridibooks、Naver Webtoon，竖着往下滑的条漫也能翻。插件直接读取屏幕上的画面，所以不能保存图片的正版阅读器也能用。

## 安装

1. [下载 ZIP](https://github.com/wren-11/manhwa-arasseo/archive/refs/heads/main.zip)，解压，把 `manhwa-arasseo-main` 文件夹放在不会误删的地方。
2. Chrome 打开 `chrome://extensions`，打开右上角“开发者模式”。
3. 点左上角“加载未打包的扩展程序”，选这个文件夹。

更新：下载新的 ZIP 覆盖旧文件夹，再到 `chrome://extensions` 点插件上的刷新按钮。

Edge、Brave、Arc 等基于 Chrome 的浏览器用同样的方法安装，但目前只在 Chrome 上测试过。

## 获取 API key

二选一：

- **通义千问**：国内首选，北京地域新用户有 100 万 token 免费额度。
- **Claude**：效果最好，按量付费。

### 通义千问

1. 登录 [阿里云百炼](https://bailian.console.aliyun.com)，开通百炼。
2. 在“模型”里搜 `qwen3-vl-plus`，点进去，打开 **“免费额度用完即停”**（默认关闭，不打开会自动扣费）。
3. 点左下角“API-KEY”，创建 key 并复制。
4. 右键插件图标 →“选项”，选“通义千问”，粘贴 key，保存。

**查看剩余免费额度：** 百炼控制台 →“模型”→ 搜 `qwen3-vl-plus` → 点进去，“免费额度”一栏会显示剩余多少 token 和到期时间。

**免费额度用完后继续用：** 在阿里云“费用中心”充值，再回到 `qwen3-vl-plus` 页面关掉“免费额度用完即停”，key 和插件设置都不用改。余额用完会变成欠费，记得留一点余额。

**在海外使用：** 翻译速度和你离服务器的距离有关。人在海外却用北京地域，每屏要等 10–20 秒；换成离自己近的地域（比如在澳洲、东南亚选新加坡），快很多。
切换方法：在控制台顶部把地域换成离你近的那个，在该地域下创建 key，再复制 Base URL 里的“OpenAI 兼容地址”，把 key 和地址一起填进插件设置。
中国站账号只有北京地域有免费额度，其他地域按量计费。按阿里云官方说明，[国际站](https://www.alibabacloud.com)新注册的账号在新加坡地域有免费额度。

### Claude

1. 登录 [platform.claude.com](https://platform.claude.com)，在 Billing 里充值。Claude Max / Team 会员可以在 claude.ai 的 Settings → Billing → API credits 里绑定，使用每月赠送的额度。
2. 在 API Keys 里创建 key 并复制。
3. 右键插件图标 →“选项”，选 Claude，粘贴 key，保存。

key 只保存在你的浏览器里，不要发给别人。

## 使用

设置保存后直接生效，不用重新加载插件。如果漫画页面在安装插件之前就已经打开，先刷新一下页面。

打开漫画，点插件图标或按 `Option + K`（Windows：`Alt + K`）。快捷键和 MangaWakatta 错开，两个插件可以同时装。

- **条漫（边看边翻）**：按一次快捷键之后，往下滑、停下来，就会自动翻新露出来的部分。译文跟着画面滚动，一话里翻过的往回翻还在，不会重复收费。换到另一话（包括在网站里点返回）或者改了窗口宽度会清空重来。
- **整话预翻译**：按 `Option + Shift + K`（Windows：`Alt + Shift + K`），或点右下角的按钮。页面会从这一话开头快速滑到底，再回到你原来的位置，你直接开始看；翻译在后台进行，优先翻你正在看的地方往下的部分。
  - 用快捷键或工具栏图标启动时，会用“录制标签页”的方式取画面，比截图快很多，标签页上会短暂出现“正在共享”的标记。从页面里的按钮启动时 Chrome 可能不允许录制，会自动改用截图（慢一些）。
  - 网站还在加载（比如 Lezhin 弹出“正在加载作品”）时会等它加载完再截。
  - 扫描时自己滚动或按键会停下；切到别的标签页会暂停，切回来自动继续。
- 某一屏有漏翻：停在那里再按一次 `Option + K`，会重新翻这一屏，已经翻好的不受影响。
- 一页一页翻的阅读器：翻页后会自动翻译新的一页，可以在设置里关掉。同一页翻过一次不会重复收费。
- 快捷键可以在 `chrome://extensions/shortcuts` 修改。

如果装了“沉浸式翻译”这类网页翻译插件，请把漫画网站设成“不翻译”，否则它会把译文再翻一遍。

## 设置

- **翻译成**：简体中文 / 英文
- **译文框**：“只盖住原文”不挡画面；“自动撑大”字更清楚，但会挡住一部分画面
- **最大字号**：小 / 中 / 大
- **翻页后自动翻译**：默认开启

## 常见问题

- **点图标没反应**：`chrome://` 页面不能用。刚装好插件的话，先刷新漫画页面。
- **快捷键没反应**：到 `chrome://extensions/shortcuts` 看有没有设上，可能被别的扩展占用了。
- **key 无效**：检查是否复制完整。通义千问的 key 和 Base URL 要在同一个地域。
- **欠费或额度用完**：到阿里云充值，或者回到北京地域使用免费额度。
- **框的位置不准**：AI 给的位置偶尔会偏，用 Claude 会好一些。

## 已知问题

- 译文是白底框盖在原文上，没有抹掉原文。
- 偶尔会漏掉一两句，或者框的位置偏移。按一下快捷键就会重翻当前这一屏。
- 目前在 Lezhin 上实测过，其他网站还没有逐个测试。

## 隐私

截图只发给你选的 AI 服务，插件没有自己的服务器。整话预翻译时录制的标签页画面只在你的电脑上处理，不保存、不上传；只有截下来的画面会像截图一样发给你选的 AI 服务。
